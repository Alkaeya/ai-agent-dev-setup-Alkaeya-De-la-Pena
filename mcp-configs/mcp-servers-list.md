# MCP Servers List

## 1. Rolldice
- **Purpose**: Simulates rolling dice for random number generation.
- **Functionality**: Provides tools to roll dice with various configurations.

## 2. Bootcamp AI Agent
- **Purpose**: Custom AI agent for bootcamp activities.
- **Functionality**: Assists with AI-related tasks in the bootcamp environment.

## 3. Calendar Booking
- **Purpose**: Manages calendar bookings and appointments.
- **Functionality**: Integrates with Cal.com to schedule and manage events.

## 4. GitHub
- **Purpose**: Interacts with GitHub repositories.
- **Functionality**: Allows querying and managing GitHub data via API.
